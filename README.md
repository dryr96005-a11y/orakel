# זיווג משמיים — אתר תדמית

אתר סטטי בעברית ובכיוון RTL עבור קהילת השידוכים. האתר מותאם למסכים קטנים וגדולים, ללא ספריות חיצוניות או שליחת פרטים אישיים.

## פרסום ב-Netlify

- תיקיית פרסום: `.`
- פקודת build: אין
- קובץ הכניסה: `index.html`
- יש לשמור את `jerusalem-hero.webp`, `favicon.svg`, `robots.txt` ו-`sitemap.xml` יחד עם `index.html`.

## תוכן שנשמר

קישור ההצטרפות ל-WhatsApp, כללי הקבוצה, פרטי המנהלים, פרטי הזכאות והמידע על השירות ללא עלות נשמרו מהגרסה הקיימת.

## קידום ושיתוף

האתר כולל כותרת ותיאור בעברית, כתובת קנונית, Open Graph, תמונת שיתוף, קובץ `robots.txt` ומפת אתר.
